HOW TO RUN
==========
1. Unzip this folder anywhere.
2. Double-click index.html — it opens in your browser. Done. No installs needed.

(An internet connection is needed once, to load the two fonts and the images.)

THE FILES
=========
index.html  -> the one to open. Holds the page structure.
style.css   -> all the design (colors, fonts, layout).
data.js     -> YOUR content: name, bio, skills, hobbies, links, images. Edit only this.
script.js   -> the behavior (typewriter, terminal, timer, animations). Leave as is.

TIPS
====
- To change anything visible, edit data.js and refresh the browser.
- Works on phones too — it's fully responsive.
